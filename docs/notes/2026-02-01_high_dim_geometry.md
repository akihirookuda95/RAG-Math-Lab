# 高次元幾何（次元の呪い）ノート

このノートは、`scripts/high_dim_geometry.py` で観察した現象（**ほぼ直交**／**距離の集中**）を、数式と直観で整理し、RAG（ベクトル検索）に接続するためのまとめです。

---

## 0. 何が言いたいノートか（結論）

- 高次元空間で「ランダムな点」を取ると、**角度も距離も“ほとんど同じ見え方”になりやすい**。\n → そのままでは「近い／遠い」を付けても差が出にくい（ランキングの信号が薄い）。
- Embedding はランダムではなく **学習によって構造が入る**。\n → 「関連があるものは角度が小さい（cos が大きい）」という **偏り**を作ることで、検索が成り立つ。

---

## 1. 用語と前提

### 1.1 期待値 $\\mathbb{E}$ とは

$\\mathbb{E}[X]$ は **確率変数 $X$ の平均**（長期平均）です。\n「ランダムに何度も試したときの平均値」と思ってよいです。

### 1.2 本ノートでの確率モデル

- $u, v \\in \\mathbb{R}^d$ を **独立**なランダムベクトルとし、各成分が標準正規分布に従うとします：

$$
u, v \\sim \\mathcal{N}(0, I_d)
$$

- 正規化（長さ 1 化）は

$$
\\hat{u} = \\frac{u}{\\|u\\|}, \\quad \\hat{v} = \\frac{v}{\\|v\\|}
$$

- コサイン類似度（角度）は

$$
\\cos\\theta = \\hat{u} \\cdot \\hat{v} = \\frac{u\\cdot v}{\\|u\\|\\,\\|v\\|}
$$

---

## 2. 「情報が出にくい」とは何か（ランキングの観点）

検索（ランキング）は本質的に「候補間のスコア差」で順位が決まります。

- 例えばクエリ $q$ に対して候補 $x_1, x_2, \\dots$ を並べたいとき\n スコアが
  - cos: $s_i = \\cos(q, x_i)$\n - 距離: $s_i = -\\|q-x_i\\|$
    のどちらだとしても、重要なのは **$s_i$ が候補ごとに十分バラつく**ことです。

ところが高次元で「候補がランダムに散っている」状況では、

- cos も dist も **分布が集中**しやすく、候補間の差が小さくなる\n → 上位・下位が“ほぼ運”になりやすい（信号が薄い）

という問題が起きます。

---

## 3. ほぼ直交：なぜ $\\cos\\theta \\approx 0$ に集中するのか

直観だけ先に言うと：

- 高次元では「方向」がとてもたくさんある\n- ランダムに選んだ 2 本のベクトルが、たまたま同じ方向を向く確率は小さい\n- 結果として「ほぼ直交」に見える（$\\cos\\theta \\approx 0$）

実験上は、$d$ を増やすと

- $\\cos\\theta$ の **平均はほぼ 0**
- $\\cos\\theta$ の **std が小さくなる**（0 付近に寄る）

という形で観察できます。

> 重要：これは **ランダムベクトル**の性質です。\n> Embedding のように学習で構造が入ると、関連ペアは 0 から正方向に“偏る”ことが起きます。

---

## 4. 距離の集中：なぜ $\\|u-v\\|$ が“だいたい同じ”になるのか

### 4.1 まず期待値（平均）を計算する

恒等式として

$$
\\|u-v\\|^2 = \\|u\\|^2 + \\|v\\|^2 - 2u\\cdot v
$$

両辺の期待値を取ると

$$
\\mathbb{E}[\\|u-v\\|^2]
= \\mathbb{E}[\\|u\\|^2] + \\mathbb{E}[\\|v\\|^2] - 2\\mathbb{E}[u\\cdot v]
$$

ここで、$u,v\\sim \\mathcal{N}(0,I_d)$ のとき

- $\\mathbb{E}[\\|u\\|^2] = d$\n （$\\|u\\|^2 = \\sum_{i=1}^d u_i^2$ で、各 $u_i^2$ の平均が 1）
- $\\mathbb{E}[\\|v\\|^2] = d$
- $\\mathbb{E}[u\\cdot v] = 0$\n （$u\\cdot v = \\sum_{i=1}^d u_i v_i$、独立で平均 0 なので各項の平均が 0）

よって

$$
\\mathbb{E}[\\|u-v\\|^2] = d + d - 0 = 2d
$$

### 4.2 「集中」の意味（平均との差が相対的に小さくなる）

「距離が集中する」とは、平均の周りに値が集まり、

- $\\|u-v\\|$ が候補ごとに **あまり変わらなくなる**

という意味です。ランキングで言うと、

- $\\|q-x_i\\|$ がどの候補でも“だいたい同じ”\n → 距離だけでは順位が付きにくい

が起きます。

（重要なのは「平均が増える」ことよりも、**候補間の相対差が出にくくなる**ことです。）

---

## 5. Q&A（誤解 → 修正を明記）

### Q1. 「cos の std が小さくなる」＝「意味が同じになり、表現の幅がなくなる」？

**A（修正）:** その理解は不正確です。\n ここで観察しているのは「ランダムな点同士」の性質で、

- $\\cos\\theta$ が 0 に集中\n → **ほぼ直交（方向が“同じ”ではなく“違いすぎる”）**

を意味します。\n「意味が同一化して幅がなくなる」というより、**“ランダムだと全部似た見え方になって差が出ない”** という話です。

Embedding では、学習で「関連ペアの角度が小さくなる」ように構造を入れるため、0 からの偏りが信号になります。

### Q2. dist が集中する意味が分からない

**A:** dist（ユークリッド距離）が集中すると、

- どの候補も $\\|q-x\\|$ が似た値になりやすい\n → **近い／遠いで順位付けしづらい**

となります。\n 検索の観点では「スコア差（信号）が薄い」という意味です。

### Q3. $\\mathbb{E}$ は何？ なぜ交差項が消えるの？

**A:** $\\mathbb{E}$ は期待値（平均）です。\n 交差項が消えるのは「高次元だから」ではなく、**独立で平均 0** だからです。

$$
\\mathbb{E}[u\\cdot v]
= \\mathbb{E}\\left[\\sum_{i=1}^d u_i v_i\\right]
= \\sum_{i=1}^d \\mathbb{E}[u_i v_i]
= \\sum_{i=1}^d \\mathbb{E}[u_i]\\,\\mathbb{E}[v_i]
= 0
$$

## 6. 実験（`scripts/high_dim_geometry.py`）との対応

出力で見るべきポイントは次の 2 つです：

- cos の `std` が d とともに小さくなる\n → 「ほぼ直交」への集中
- dist の `std`（特に mean に対する相対的な大きさ）が小さくなる\n → 「距離の集中」

この“集中”は、**ランダムな点**では「順位付けの信号が出にくい」ことを示します。\nRAG では、学習された embedding が「関連ペアに偏り」を作ることで、cos/内積を信号として使えるようにします。

### 7.1 cos（角度）が意味していること

- **mean がほぼ 0**：\n ランダムベクトル同士は、平均的には「同じ方向でも逆方向でもない」＝ **直交に近い**（$\\cos\\theta\\approx 0$）。

- **std が d とともに小さくなる**：\n $d=2$ では `std≈0.71` と大きく、いろいろな角度が出ます。\n しかし $d=8192$ では `std≈0.011` まで小さくなり、ほとんどのペアが **$\\cos\\theta=0$ の近く**に張り付く。\n これは「高次元ほど意味が同一化する」というより、**ランダムに取った点同士の角度が“ほぼ全部同じ（直交）”に見える**という現象です。

直観：

- 低次元（2D）だと「方向が近い」「方向が遠い」が割とはっきり出る\n- 高次元だと、ランダムに選ぶ限り「どれも同じくらい直交」に見える\n → 角度で近いものを探そうとしても、**ランダムな集合には“近い”がそもそも生まれにくい**

### 7.2 dist（距離）が意味していること

ここが一番重要です。\n あなたのログでは dist の `std` はだいたい `≈1` のままですが、mean は d とともに大きくなっています：

- $d=2$：`mean≈1.77`, `std≈0.94`\n- $d=8192$：`mean≈128.01`, `std≈1.02`

このとき「集中」を見る正しい見方は、**std の絶対値そのもの**ではなく **相対的な揺れ**です。\n つまり `std / mean` を見ます。

- $d=2$：$\\frac{\\mathrm{std}}{\\mathrm{mean}} \\approx \\frac{0.94}{1.77} \\approx 0.53$\n → 距離がかなりブレる（近い/遠いが割と区別できる）
- $d=8192$：$\\frac{\\mathrm{std}}{\\mathrm{mean}} \\approx \\frac{1.02}{128.01} \\approx 0.008$\n → 距離がほぼ一定（**どれも同じくらいの距離**）

これが「距離の集中」です。\n\n 検索（ランキング）で言うと、クエリ $q$ に対して多数の候補 $x$ があるとき：

- 低次元：$\\|q-x\\|$ の差が大きめに出るので順位が付きやすい\n- 高次元（ランダム集合）：$\\|q-x\\|$ がみんなほぼ同じになり、順位が付けにくい\n → 距離だけでは「関連性」の信号が出ない

### 7.3 RAG/Embedding にどう接続するか

この実験は「ランダム点」なので、距離も角度も差が出にくくなります。\n しかし Embedding は学習により、次を満たすように“空間を歪めます”：

- 関連がある（意味が近い）ペア：$\\cos(q,x)$ が **0 から正方向に偏る**（角度が小さくなる）
- 関連がないペア：$\\cos(q,x)$ は **0 付近**に留まりやすい

高次元の「デフォルトが 0 付近に集中」だからこそ、学習で生じた **わずかな偏り**がランキングの強い信号になります。
